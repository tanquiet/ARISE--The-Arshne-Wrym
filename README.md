# ARISE: The Arshne Wrym 🐉

A gamified habit tracker where sticking to your habits helps you progress and unlock rewards — day by day, one streak at a time.

## About

ARISE turns habit-building into a game. Create the habits you want to build, check in on them each day, and watch your progress unlock as you stay consistent. The "Arshne Wrym" theme frames your daily discipline as a journey of growth — the more consistently you show up, the further you advance.

## Features

- **Create habits** — add the daily habits you want to track and build
- **Daily progress tracking** — check off habits as you complete them each day
- **Unlockable progression** — staying consistent unlocks new stages/rewards as you go
- **Simple, lightweight interface** — runs directly in the browser, no install required

## Getting Started

This is a single-file browser app — no build step or dependencies required.

1. Clone the repository:
   ```bash
   git clone https://github.com/tanquiet/ARISE--The-Arshne-Wrym.git
   ```
2. Open the HTML file in your browser:
   ```bash
   cd ARISE--The-Arshne-Wrym
   open "arise (8).html"   # or just double-click the file
   ```
3. Start creating habits and check in daily to track your progress.
